# 🛍️ پلتفرم فروش بدون سرمایه (Dropshipping Marketplace) — MVP

> **پیام اصلی:** «بدون سرمایه فروشنده شو و از هر سفارش سود بگیر.»

نمونه اولیه اجرایی (MVP) مرحله اول طرح جامع — شروع از **مزارشریف** با پرداخت هنگام تحویل (COD).

## ✨ امکانات MVP

| نقش | امکانات |
|---|---|
| 🛍️ **فروشنده** | ثبت‌نام رایگان، انتخاب از کاتالوگ، تعیین سود دلخواه + پیشنهاد هوشمند قیمت، لینک فروشگاه اختصاصی (اشتراک در واتساپ/تلگرام)، داشبورد درآمد، سفارش‌ها، تسویه |
| 📦 **تأمین‌کننده** | ثبت/ویرایش محصول، مدیریت لحظه‌ای موجودی، مشاهده سفارش‌های دریافتی |
| 🛠️ **ادمین** | نمای کلی (GMV، درآمد پلتفرم، بدهی‌ها)، مدیریت وضعیت سفارش‌ها، کاربران و پلان‌ها، تسویه فروشندگان |
| 🧾 **مشتری** | خرید از لینک فروشنده بدون نیاز به حساب، پرداخت هنگام تحویل، پیگیری با کد سفارش |

## 🚀 اجرا (کمتر از ۲ دقیقه)

```bash
cd DropshipMarketplace
pip install -r requirements.txt
python3 seed.py        # ساخت دیتابیس + داده نمایشی (فقط بار اول)
python3 app.py         # اجرا روی http://localhost:5000
```

سپس مرورگر: **http://localhost:5000**

## 🧪 حساب‌های نمایشی

| نقش | شماره ورود |
|---|---|
| فروشنده | `0700000003` |
| تأمین‌کننده | `0700000002` |
| ادمین | `0700000001` |

> ورود فقط با شماره تماس است (مخصوص دمو). در نسخه واقعی باید رمز/کد تأیید پیامکی اضافه شود.

## 💰 مدل مالی (خودکار در هر سفارش)

```
قیمت فروش = قیمت عمده + سود فروشنده
پرداخت مشتری = قیمت فروش × تعداد + هزینه ارسال (۱۰۰ ؋)
سود فروشنده = سود × تعداد        → بعد از تحویل، قابل تسویه
سهم تأمین‌کننده = قیمت عمده × تعداد
کارمزد پلتفرم = ۵٪ قیمت عمده
```

چرخه وضعیت سفارش: `در انتظار → تأیید → ارسال → تحویل` ✅ (یا لغو/مرجوعی ↩️ با برگشت خودکار موجودی)

    ├── seller.html   # پنل فروشنده
    ├── supplier.html # پنل تأمین‌کننده
    ├── admin.html    # پنل ادمین

    └── api.js        # توابع مشترک API/احراز هویت

## ⚠️ محدودیت‌های آگاهانه MVP

- احراز هویت ساده (توکن نمایشی) — نیاز به OTP/رمز در نسخه واقعی
- بدون درگاه پرداخت آنلاین (عمدی: بازار افغانستان = COD)
- عکس واقعی محصول ندارد (ایموجی) — افزودن آپلود عکس در فاز بعد
- تک‌فروشنده در هر سفارش — سبد چندفروشنده‌ای در فاز بعد

جزئیات فنی و نقشه راه را در [ARCHITECTURE.md](ARCHITECTURE.md) بخوانید.
